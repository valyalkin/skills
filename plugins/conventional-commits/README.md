# conventional-commits

Writes git commit messages and pull request titles that follow the
[Conventional Commits](https://www.conventionalcommits.org/) specification, derived from the
staged diff rather than from the request that produced it.

## Skills

| Skill | Triggers on |
| --- | --- |
| `conventional-commits` | "commit", "write a commit message", "name this PR", rewriting an existing message |

## Install

```
/plugin marketplace add <owner>/skills
/plugin install conventional-commits@alex-skills
```
